Page 1 — Market Scanner Dashboard

Route: /myCabinet/screener · Files: page.tsx, Filters.tsx, AssetsTable.tsx, TableRow.tsx.

Columns

RequirementStatusNotes / Gap
Symbol (pair) with icon DONE Implemented in TableRow.tsx with image fallback.

Recent liquidations $ (last 1h total) PARTIAL Implemented as two columns (Liq Buy, Liq Sell) tied to the Period toggle. Spec wants a single rolling 1h $ total to flag unusual activity at a glance.

Frontend work that needs to happen, by priority

High priority — directly blocks the spec's stated workflow

  • P0 Dashboard column rework: show OI 1h / 4h / 24h side-by-side instead of one period-toggled column; add Volume Spike % and 1h-Total Liquidation $.
  • P0 Exchange filter (Binance, MEXC, …) — add exchange to AssetPair and a select control to Filters.tsx.
  • P0 Real preset filters: wire "High OI Spike" and "Negative Funding" buttons to predicates instead of leaving them disabled.
  • P0 Order Book (L2 depth) panel in the terminal sidebar — currently absent.
  • P0 Footprint (Cluster) chart mode — replace/extend the heatmap stub with a true footprint that prints bid/ask per price level and per-candle delta.

Medium priority — improves the analysis loop

  • P1 Pattern recognition column with a badge per row + tooltip; needs a patterns[] field on the asset.
  • P1 VDelta 1h + 4h dual column, dropping period-toggle dependency.
  • P1 Funding-extreme warning highlighting with thresholds (e.g. |fr| > 0.05% = yellow, > 0.1% = red).
  • P1 Terminal sub-panel reorganization: OI+Volume in one pane, Liquidations+Funding-line overlay in another, to match the spec's three-panel layout.
  • P1 Time & Sales tape: show all prints by default; add a "large only" toggle. Keep LiquidationsFeed alongside.
  • P1 Global timeframe control in the page header, governing master chart + sidebar panels.

Lower priority — value-add, not workflow-critical

  • P2 Telegram alert configuration UI — chart context menu + alert-rule modal + management page.
  • P2 On-chain events panel (large exchange inflows/outflows for the active asset).
  • P2 Market-cap filter (low-cap focus) — needs a marketCap field per pair.
  • P2 Infinite-history loader on the master chart (already stubbed).
  • P2 Fixed 24h % column for price, decoupled from the period toggle.

Scope note: this report only inventories frontend gaps relative to the spec. All current data flows through src/lib/screener/mock/ with TODO(real-data) markers pointing to the future REST and WebSocket endpoints; wiring those is a separate backlog.
